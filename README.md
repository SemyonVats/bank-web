# Bank Web

Небольшое банковское веб-приложение на Java.

Приложение позволяет создавать клиентов банка и их счета, просматривать баланс, пополнять счет и снимать с него деньги. Для работы с приложением используется веб-интерфейс, который открывается в браузере.

## Функциональность

- создание клиентов;
- поиск клиентов;
- создание банковских счетов;
- просмотр счетов клиента;
- просмотр баланса;
- пополнение счета;
- снятие денег;
- изменение баланса;
- защита от отрицательного баланса;
- параллельная обработка запросов.

## Язык

Java 25

Frontend: HTML, CSS, JavaScript.

## Запуск

Скомпилировать проект:

```powershell
New-Item -ItemType Directory -Force out
javac -encoding UTF-8 -d out java\*.java
```

Запустить:

```powershell
java -cp "out;." BankApplication
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:8080
```
